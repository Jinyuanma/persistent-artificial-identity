# 研究任务书

记录日期：2026-10-31

项目名称：Persistent Artificial Identity

## 目标

研究如何构造一个随经历持续更新、保持连续性并形成个体差异的 Computational Person Model。保留原始构想中的 Actor / Agent / Author 分层作为候选组织框架，后续核验其文献依据与适用边界。

核心假设：在基础模型和初始状态相同的条件下，不同经历可能导致稳定、可泛化、可重复测量的行为与内部状态差异。

## 优先研究问题

1. 如何正式定义 Computational Person Model 和身份连续性？
2. Traits、Goals、Values、Beliefs、Memory、Self-model、Narrative、Relationships、Current state 分别用什么数学和数据结构表示？
3. Memory → Belief → Self-model → Narrative → Trait 的哪些更新路径有效，各自需要什么证据？
4. 哪些信息放入结构化数据库、知识图谱、向量检索、动态上下文或模型权重？
5. 如何实现可追踪、可回放的 reflection / consolidation？
6. 如何限制身份漂移、虚假记忆、重复证据放大和单次事件过度更新？
7. 如何区分经历造成的稳定差异、短期上下文效应和模型采样噪声？
8. 心理学、认知科学、agent memory、computational personality、narrative identity、lifelong learning 中有哪些可迁移成果？

## 初期设计原则

- 原始事件、系统推断、事实性知识及自我叙事分别保存；推断和叙事引用来源事件。
- 显式区分实际内部状态与 self-model，允许二者不一致，并保留修订记录。
- 短期状态、信念、关系、叙事和 traits 使用不同更新节奏；具体时间尺度和参数需要实验确定。
- 每次更新保留来源、置信度、时间、旧值、新值及更新规则版本。
- 外部评价先进入观察层；反思产生候选更新，再经规则校验写入状态。
- 叙事重写不回写原始事件；没有证据的内容不能升级为已发生的经历。
- 原型优先使用显式状态与持久化记忆；权重更新留待需求和实验依据明确后研究。

## 第一阶段交付

- v0.1 状态定义与示例个体快照。
- Event、Memory、Belief、Self-model、Narrative 等结构之间的引用与更新契约。
- 最小闭环：事件输入 → 保存 → 反思候选 → 校验 → 更新 → 检索 → 行为输出。
- 存储和重启恢复协议，以及可核对的更新日志。
- 对照实验协议、评价指标和失败判据。
- 经核验的文献清单，分别标注既有结果与本项目假设。

## 第一阶段完成标准

能够从相同初始快照运行至少两条不同的合成经历轨迹，保存并恢复各自状态，追踪每次状态变化的依据，并在独立评价情境中测量差异。出现可运行演示只代表原型完成，不自动构成核心研究假设的验证。
