# 研究路线图

启动日期：2026-10-31。以下任务尚未完成；顺序可随文献和实验发现调整。

## M0：定义与证据

- [ ] 核验 Actor / Agent / Author、narrative identity 及相关认知架构的原始文献。
- [ ] 调查 agent memory、反思机制、长期个性化与 lifelong learning 的已有系统。
- [ ] 定义 identity persistence、development、individual divergence 的操作性含义。
- [ ] 明确哪些结果会反驳或削弱核心假设。

交付：带出处的文献矩阵与研究问题定义。

## M1：v0.1 状态与更新规范（首要任务）

- [ ] 定义个体标识、版本、时间语义和可恢复快照。
- [ ] 定义各类心理变量的 schema、取值范围、置信度与来源引用。
- [ ] 定义原始事件、记忆、推断和叙事的边界。
- [ ] 定义各变量的更新触发条件、变化上限和冲突处理规则。
- [ ] 确定首版存储方案；对数据库、图、embedding、context、weights 的取舍写出理由。

交付：状态规范、合成样例和更新契约。

## M2：最小持久化闭环

- [ ] 实现合成事件输入和持久化保存。
- [ ] 实现按当前情境检索相关记忆。
- [ ] 实现带证据引用的 reflection / consolidation 候选输出。
- [ ] 校验候选更新，记录接受与拒绝的原因。
- [ ] 实现从状态到模型上下文的动态构建。
- [ ] 验证重启恢复、事件回放、重复事件处理和来源追踪。

交付：可运行演示、运行说明和可审查轨迹。

## M3：受控实验

- [ ] 固定基础模型版本、初始状态、初始知识和评价场景。
- [ ] 设置相同经历重复组，估计模型与采样造成的自然差异。
- [ ] 设置不同经历组，在相同的独立评价场景中比较。
- [ ] 设置静态 persona、仅记忆、记忆加反思等基线与消融。
- [ ] 使用多条轨迹和重复运行，记录提示、配置、模型版本、随机种子及实际输出；不假定外部模型完全可复现。
- [ ] 评价行为差异、经历一致性、重启后的持续性、跨情境稳定性、错误记忆和身份漂移。
- [ ] 检查仅有措辞差异、短期情绪效应或身份描述差异时，是否被错误认定为稳定个体差异。

交付：实验协议、结果、限制及失败案例。先做小规模试验，成本与指标合理后再考虑原始构想中的 100 个 agent。

## M4：长期发展

- [ ] 探索叙事修订、关系演化及慢速 traits 更新。
- [ ] 测试长时程遗忘、冲突经历、证据撤回和恢复机制。
- [ ] 根据实验需要决定是否研究 LoRA 或其他权重更新方案。

交付：长期轨迹分析与下一轮研究决策。
